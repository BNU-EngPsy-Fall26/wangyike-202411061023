01先从一个日常场景说起

场景
你正在开车。收音机开着，路面有噪音。突然，你好像听到引擎传来一声轻微的异响——“咔嗒”。 你的车很旧，以前也出过毛病。那么问题是：你听到的到底是真的异响，还是只是路噪和收音机里的声音让你产生了错觉？

这个场景里其实包含了两层不确定性：

第一层：世界上到底有没有异响？引擎可能真的发出了异响（信号存在），也可能一切正常（只有噪音）。
第二层：你的判断是什么？你可以决定“我听到了异响”，也可以决定“那是错觉，没有异响”。

两层组合起来，就是四种可能的结果。点击下面的格子，了解每一种的含义。

每个格子代表一种结果。注意：正确的格子（击中、正确拒斥）和错误的格子（误报、漏报）各有两个， 但它们错误的“代价”完全不同——漏报可能让你在半路抛锚，误报只是多跑一趟修理厂。

信号检测论最核心的洞察就是：你不可能同时消灭误报和漏报。 你只能选择把判断的门槛设在哪里。门槛设得高，漏报多、误报少；门槛设得低，误报多、漏报少。

02“你能不能分得清？”——辨别力 d′

上面说的“门槛”问题，前提是你能感受到差异。 如果引擎的异响和路噪在你听起来完全一样，那无论门槛设在哪里都没用。

信号检测论用两个正态分布来刻画这个“感受”：

噪音分布 N(0, 1)
只有背景噪音时，你感受到的“异响强度”波动。大多集中在 0 附近，偶尔也会偏大——这就是为什么你有时会在完全正常的车里“听到”异响。
信号分布 N(d′, 1)
真的存在信号（异响）时，你感受到的强度波动。它的平均值比噪音分布高出 d′。两个分布重叠得越少，越容易分辨。
辨别力 d′ 1.50
观察
拖动滑块，看两个分布如何分离。d′ 越大，分布越分开，你越不容易把噪音误认成信号。

注意：分布本身并没有移动到你“想要”的位置。你感受到的波动是被动发生的—— d′ 决定了你的感官系统能把信号从噪音中区分出来的物理极限。

换句话说，d′ 回答的是：“如果我想分清楚，我有没有这个能力？” 而不是“我愿意分多清楚”。

03“你敢不敢说有？”——判断标准 c

假设 d′ 已经固定了——你的耳朵就是那么灵，或者就是那么不灵。现在轮到你来做决定了。

你需要在感觉轴上划一条线：“感觉强度超过这条线，我就说有异响；没超过，我就说没有。” 这条线就是判断标准，通常用 c 表示。

这就是信号检测论最关键的一步：把“能力”和“策略”分开。 在传统的“准确率”框架下，你无法区分“谨慎的人”和“能力差的人”—— 他们的准确率可能一样，但 d′ 和 c 完全不同。

04什么决定了你的 c？

你不会凭空选择判断标准。两个因素在背后推动你：

因素一：信号出现的先验概率

如果你知道这条路上有 90% 的概率会有异响（比如这条路以路面颠簸出名）， 你会更倾向于说“有”。相反，如果这条路你天天走、从来没事，你会更倾向于说“没有”。

工程心理学的核心
现实中的检测者——雷达操作员、安检员、医生——并不是“尽量准确”就行。 他们的 c 会被先验概率、奖惩结构、组织文化、甚至一句“宁可错杀不可放过”所塑造。 信号检测论的价值就在于：它能把“这个人能力如何”和“这个人被要求怎么做”分开测量。
