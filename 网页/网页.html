你是地震台网的监测员。屏幕上是一段 60 秒的地面震动记录—— 大多数时候只是风、车流和脚步的背景噪声，偶尔会藏进一次微弱的微震。 你的任务只有一句话：这段记录里，到底有没有事件？

实验设置

微震与噪声在感觉上的分离程度。调小它，事件就更容易被淹没在噪声里。

概念讲解

你将会经历什么

  • 1先看一段一分钟的操作教程。
  • 2每试次播放一段 60 秒的地震记录（约 2 秒看完）。
  • 3记录消失后，你要判断：有微震，还是只有噪声。
  • 4结束后，我们不只算「对了多少」，而是把你的表现拆成两件事。

先别急着看答案

大多数人玩完，第一反应是看「我答对了百分之多少」。 但在信号检测论里，准确率恰恰是最没有信息量的那个数字。 真正要看的是两个更基本的量：d′（辨别力） 与 c（判断标准）。

它们回答两个完全不同的问题——
d′：你能不能分得清？　信号和噪声在你的感觉里离得有多开。
c：你敢不敢说有？　你心里的报警门槛设在了哪里。

同一个人的 d′ 在一段时间里基本稳定，但 c 可以被一句话改变： 「宁可错报，也别漏报」——你还没开始玩，标准就已经动了。

实验结果 · Signal Detection Theory

你答对了多少，其实说明不了什么

辨别力 d′ ｜ 你能不能分清
—
d′ = Z(击中率) − Z(误报率)
判断标准 c ｜ 你敢不敢说有
—
c = −[ Z(击中率) + Z(误报率) ] / 2

d′ 与 c 到底在说什么

信号检测论认为，每一次判断背后都同时发生了两件事。 一件是感觉过程：纯噪声、以及「噪声＋信号」， 在你的知觉系统里形成两个各自起伏的分布，它们重叠得越少，你越容易分辨—— 这个分离程度就是 d′。

另一件是决策过程：你在两个分布之间画了一条竖线， 感觉超过了它就说「有」，没超过就说「没有」——这条线的位置就是 c。

说得直白一点：d′ 描述你的眼睛，c 描述你的胆子。 前者由信号本身和你感官的灵敏度决定，后者由动机、期望、奖惩，甚至一句口头指示决定。

Z 表示把比率换算成标准正态分布上的分数（Z 分数）。 d′ 就是这两个 Z 分数之差，c 是它们和的一半取负号。

ROC 曲线：把 c 从 d′ 里剥出来

横轴是虚报率 P(FA)，纵轴是击中率 P(H)。当信号强度固定时， 如果你把判断标准从极严一路调到极松，得到的点就会连成一条弯曲的 ROC 曲线—— 这条曲线的形状只由 d′ 决定，而你在曲线上的位置只由 c 决定。

这正是信号检测论最漂亮的地方：一个数据点，同时携带了能力与策略两条信息。 沿曲线滑动＝改变标准；把整条曲线往左上角推＝提高辨别力。

浅青细线 d′ = 0.5 / 1.0 / 1.5 / 2.0 / 2.5 / 3.0 ｜ 对角线为 d′ = 0 的随机猜测

准确率陷阱：为什么教科书不用它

假设微震的实际发生率只有 10%。一个从头到尾都回答「没有」的监测员， 什么也没做，准确率却有 90%。准确率把漏报和虚报一视同仁地算作错误， 可在真实的地震台网里，这两种错误的代价天差地别。
